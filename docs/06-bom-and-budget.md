# BOM Targets and Budget / เป้าหมาย BOM และงบประมาณ

## Cost boundary / ขอบเขตต้นทุน

Targets below are engineering caps, not exchange-rate conversions or supplier quotes. They exclude the GeX rear derailleur, existing bicycle, tools already owned, bike computer, and labor.

ตัวเลขด้านล่างเป็นเพดานงานวิศวกรรม ไม่ใช่อัตราแลกเปลี่ยนหรือใบเสนอราคาผู้ขาย ไม่รวมตีนผี GeX จักรยานเดิม เครื่องมือที่มี ไมล์จักรยาน และค่าแรง

- **Paddle mechanics only / ชุดแป้นเชิงกลเท่านั้น:** target ≤ THB 500 total for two sides. / เป้าหมายไม่เกิน 500 บาทรวมสองข้าง
- **V1 using retained/donor GeX transmitter / V1 ใช้วงจรส่ง GeX เดิม:** target ≤ THB 1,500 incremental, excluding donor value. / เป้าหมายต้นทุนเพิ่มไม่เกิน 1,500 บาท ไม่รวมมูลค่าชิ้นส่วนต้นทาง
- **Custom-radio research cap / เพดานวิจัยวิทยุทำเอง:** do not start or spend until separately approved after the donor-path decision. / ห้ามเริ่มหรือใช้เงินจนกว่าจะอนุมัติแยกหลังตัดสินช่องทางชิ้นส่วนต้นทาง

## Purchase gates / จุดอนุมัติการซื้อ

1. **Before R0:** buy nothing; record exact hardware already owned. / **ก่อน R0:** ไม่ซื้อ บันทึกอุปกรณ์ที่มีให้ครบ
2. **After R0:** only inexpensive mockup materials and two candidate switches. / **หลัง R0:** ซื้อเฉพาะวัสดุแบบจำลองและสวิตช์ตัวเลือกสองรุ่น
3. **After donor contact test:** buy final wire, connectors, enclosure, and duplicate left/right mount. / **หลังทดสอบหน้าสัมผัสต้นทาง:** ซื้อสาย คอนเน็กเตอร์ กล่อง และจุดยึดซ้าย/ขวา
4. **After Gate A:** approve durability/weather materials. / **หลัง Gate A:** อนุมัติวัสดุความทนทานและกันสภาพอากาศ
5. **Custom RF:** separate budget decision only. / **RF ทำเอง:** ตัดสินงบแยกเท่านั้น
